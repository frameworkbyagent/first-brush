# PRD — First Brush

## Продукт
First Brush — семейное web-приложение для спокойной вечерней очереди чистки зубов между Давидом и Анной.

## Проблема
Вечером детям нужен понятный и предсказуемый порядок без споров. Родителю нужен очень быстрый и наглядный инструмент, который поддерживает рутину, а не отвлекает от неё.

## Ключевая идея
Приложение не про соревнование. Оно про спокойную последовательность:
1. сначала один ребёнок
2. потом второй
3. потом общий экран, что на сегодня всё готово

## Пользователи
- Дети: Давид и Анна
- Родитель

## Product principles
- visual-first: аватары важнее текста
- one-step-at-a-time: на экране только текущий шаг
- calm routine: без давления, гонки и лишнего шума
- parent-safe: изменения порядка только через родительский режим
- fast daily use: открыть, нажать, закрыть

## Current MVP scope
- один активный ребёнок на основном экране
- большая кнопка `Готово`
- переход first -> second -> done
- финальный экран завершения дня
- аватары детей как основная навигация
- родительский PIN
- reset дня
- ручное изменение порядка на сегодня
- локальное сохранение состояния
- Docker запуск в домашней сети

## Out of scope for now
- аккаунты и облачная синхронизация
- многосемейный режим
- сложная геймификация
- push-уведомления
- аналитика

## Acceptance criteria
- ребёнок понимает, кто идёт сейчас, без чтения текста
- после нажатия `Готово` приложение мягко переводит к следующему шагу
- после второго ребёнка показывается экран завершения дня
- состояние сохраняется между рестартами
- родитель может безопасно поменять порядок через защищённый режим

## Next product priorities
1. миграция старого state schema в новый формат
2. более чистый parent mode / settings flow
3. тесты на state machine
