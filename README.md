# First Brush

Семейное web-приложение для вечерней очереди чистки зубов.

## Идея
Приложение показывает, кто сегодня чистит зубы первым, и автоматически чередует очередь между детьми по дням.

## MVP
- главный экран: кто сегодня первый
- отметка о выполнении вечерней чистки
- автоматическое чередование Давид ↔ Анна
- история по дням
- ручная коррекция очереди


## Локальный запуск

```bash
npm install
npm run dev
```

Открыть в браузере:
- http://192.168.100.78:3000

## Что уже есть

- Next.js app router
- mobile-first главный экран
- локальная логика чередования Давид ↔ Анна по дням
- мок-история последних 7 дней
- кнопки для будущих действий: подтверждение и ручная коррекция

## Ключевые файлы

- `app/page.tsx` — главный экран
- `components/queue-card.tsx` — UI карточки очереди
- `lib/queue.ts` — логика чередования и история
- `app/globals.css` — стили MVP


## Сохранение данных

Приложение хранит состояние в `data/state.json`.

Там сохраняются:
- кто сегодня первый
- отмечена ли чистка на сегодня
- история по дням
- ручные переключения очереди

В Docker это переживает рестарты через volume `../data:/app/data`.
